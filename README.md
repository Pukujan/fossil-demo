# FOSSIL Demo

Public product shell for FOSSIL.

This repository owns the frictionless web/demo experience around `Pukujan/fossil-core`. It does **not** redefine FOSSIL completeness, provenance, citation, lineage, lifecycle, durable identity, or projection authority.

## Current V0

The first slice is intentionally narrow:

```text
public ChatGPT share URL
    -> temporary anonymous workspace
    -> honest capture/completeness state
    -> FOSSIL-backed memory view
    -> grounded query + evidence
    -> deterministic verify
    -> delete now
```

Product planning and contracts live in:

- #1 — product/demo epic
- #2 — V0 UX/storyboard/state contract
- #3 — V0 product-facing API contract
- #4 — first implementation vertical slice

The initial public surface is intended to integrate with the Design Bakery FOSSIL product page while the live workspace remains isolated on its own application origin.
